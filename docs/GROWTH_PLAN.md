# 봇 성장 단계 계획 (초기 → 중기 → 후기)

봇이 시간이 아니라 **자기 상태 기준**으로 단계를 전환하는 설계.
(같은 시각에도 앞선 봇은 중기, 털린 봇은 초기로 되돌아갈 수 있음)
전략 근거: [strategies.md](strategies.md) / 현재 구현 상태 기준일: 2026-07-11

## 1단계: 초기 — 경제 기반 ✅ 구현됨

**전환 조건**: 게임 시작 ~ 성격별 자원건물 기준선 도달 (예: 채굴러 메탈 Lv.6)

- 태양광 흑자 유지하며 메탈 → 크리스탈 → 듀테륨 순환 건설
- 에너지 음수면 성격 무관 태양광 강제
- 행동: 건설 1건/틱

**저장고 기준선 (전 성격 공통, 초기부터 항상 적용)** ✅ 구현됨
자원은 창고 용량 상한(planets.*_max, 기본 10000)에서 잘리고, 저장고가 없으면 광산 레벨이
오를수록 건설비가 상한을 넘어 서버가 그 건설을 조용히 취소한다(정체의 근본 원인). 그래서
저장고(metal_store 22 / crystal_store 23 / deuterium_store 24)를 성격과 무관하게 다음 기준으로
자원건물보다 먼저 판정한다(우선순위: 에너지비상 > 저장고 > 기존 계획):
- **선제**: 다음 목표(자원건물/시설)의 단일자원 비용 > 그 자원 용량 × 0.9 → 해당 저장고 우선.
- **반응**: 자원이 용량의 95% 이상인 상태가 2틱 지속 → 해당 저장고 우선(생산 낭비 방지).
구현: personality.plan_primary + storage.py(상태 파일로 2틱 스트릭·백오프 관리),
용량/비용은 db_reader.get_resource_state_db + game_objects.object_cost 로 계산.

## 2단계: 초중기 — 시설과 분기 ✅ 구현됨

**전환 조건**: 자원 기준선 충족

- 로봇공장 → 연구소 → 조선소 (3틱에 1번은 자원건물 병행)
- 성격별 분기 시작: 레이더는 전투기+무기연구, 채굴러는 수송선+에너지연구 등
- 레이더(공격형): 함선 생기면 정찰→기댓값 판단→약탈 시작 ✅
- 행동: 건설 1 + 연구/함선 1 + (레이더) 함대 1

## 우선순위 재편 (2026-07-11 피드백 반영)

1. **하이브리드 구조 (최우선)** — AI는 30~60분마다 JSON 정책(건설 우선순위·공격 임계값·방어 투자 비율)만 출력, 규칙봇 엔진이 2분 틱마다 읽어 집행. 현행 "codex가 파이썬 직접 실행"은 제일 비싸고 제일 느린 방식. memory.md 2~3줄보다 상태 승계도 깔끔해짐. → 큐잉 최적화 완료 직후 착수
2. **메트릭 수집** ✅ — scripts/metrics_collector.py (5분 간격 SQLite 시계열: 봇별 점수/자원/건물/방어/함선 + 전투·약탈 기록 + 로그 로테이션 부수임무)
3. **배싱 가드** 🔨 — 타겟당 24시간 6회 공격 상한 (tick-optimize 에이전트에 지시됨). 없으면 채굴러 영구 농장화 → 레이더 독주 조기 수렴
4. **AI 통신 채널** — 인게임 메시지 읽기/보내기 + 얼라이언스 생성/가입을 AI에게 개방. 없으면 100개의 독립 최적화 루프일 뿐, 창발(동맹 제안, 전문화)은 대화에서 나옴
5. **상태 조회 DB 직독** — 액션은 HTTP 유지(게임 로직), 자원/레벨 "조회"만 읽기 전용 DB로. HTML 파싱 취약성 제거 + 요청량 대폭 감소. 식민 확장으로 행성 수 늘면 필수

## 4단계: 후기 — 전쟁 경제 📋 구상

**전환 조건**: 식민지 2개+ / 함대 규모 일정 이상

- **플릿세이브**: 잘 곳 없는 자원/함대를 수송 미션으로 회피 (strategies.md §6) — 레이더끼리 서로 털기 시작하면 필수
- **함대전**: 레이더가 상대 "함대"도 타격 (지금은 자원만) → 데브리 필드 생태계 활성화
- **타겟 정보 공유 없음 유지**: 봇마다 독립 판단 (담합 방지, 자연스러운 생태계)
- **성장 재투자 균형**: 광산:함대:방어 비율을 성격별로 (경제가 죽으면 회복 우선)
- AI 에이전트 고도화: 은하 정찰 결과·함대 이벤트를 판단 입력에 추가, memory.md 장기 전략화

## 안전장치 (전 단계 공통)

- 사람 계정(은하1 시스템44)은 공격 금지
- 조용한 실패 대응: 다음 틱 재확인으로 자기 교정
- 함대 행동 틱당 1건 + 타겟 쿨다운 (과공격 방지)
- 서버 부하 상한: 바퀴 시간이 인터벌을 크게 넘으면 조회 캐시부터 최적화
