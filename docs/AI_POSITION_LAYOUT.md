규칙봇 자산/좌표는 변경하지 않았다. AI 9개 계정의 일반 행성 24개만 옮겼고 ai01의 2개
행성은 이미 혼합 구간이라 유지했다. 주행성만 떼어 보내지 않고 식민지도 같은 목표 시스템으로
옮겨 fleetsave·식민지 개발 군집을 보존했다.

## 안전 처리

- planet ID와 user 소유권, 자원·건물·연구·함선·방어는 모두 그대로다.
- 적용 당시 활성 미션 8건의 `planet_id_from/to` 좌표 스냅샷을 새 행성과 함께 갱신했다.
- 활성 미션↔행성 좌표 불일치: from 0 / to 0, 임시 galaxy=99 잔존 0.
- 진행 중 식민 미션 목적지 및 모든 규칙봇/사람 행성과 목적지 충돌 0.
- 역사 espionage report 242건은 메시지 FK 때문에 보존했다. old 좌표는 빈 슬롯이 되고 scan
  cache 15개와 pending preflight를 만료해 새 좌표에서 다시 정찰한다.
- 레이더 상태 4개는 공격/배싱 이력만 동일 행성을 따라 새 좌표로 옮겼다.
- 적용 후 dry-run `changed_planets=0`으로 멱등성을 확인했다.
- 첫 라이브 바퀴 100/100, 64.4초. ai06이 새 군집에서 `1:20:11` 데브리를 수거하고
  식민지 `1:22:4`를 개발해 새 좌표 경로를 확인했다.

DB 롤백 백업 prefix: `ops_ai_rebalance_20260712_203333_*`. 최초 FK 거부 시도는 트랜잭션
전체가 롤백됐고 별도 사전 백업 prefix만 남았다.
