# v2 대화 세계 실험 (freeworld_chat)

자유 세계 실험(`docs/v2_freeworld`)에서 두 가지를 바꿔 다시 돌렸다.

1. 플레이어끼리 메시지를 주고받을 수 있다.
2. 비활성 farm을 없앴다. 털 곳이 없으면 플레이어끼리 부딪히는지 보려는 것이다.

두 가지를 함께 바꿨기 때문에, 아래 차이가 대화 때문인지 farm이 없어서인지는 이 판만으로 가를 수 없다. 대화만 넣고 farm은 남긴 판(`freeworld_chat_farm`)으로 따로 확인했다(아래 마지막 절).

## 설정

- 설정 파일: `sim/configs/freeworld_chat.json` (seed 7, 960턴)
- 플레이어: 자유 LLM 16명(`fr`, `fw`), v1 규칙봇 8명(`cl`), 정책 고정봇 8명(`st`). farm은 0개.
- 자유 플레이어가 새로 받은 것:
  - `messages`: 정책을 고칠 때(48턴마다) 최대 3개를 보낸다. 받는 사람은 특정 플레이어 이름이나 `all`이다. 받는 쪽은 다음 갱신 때 읽는다. 규칙봇은 읽지 못한다.
  - `excluded_players`: 여기 적은 플레이어는 엔진이 정찰하지도 공격하지도 않는다. 누가 누구를 적었는지는 모두에게 공개된다.
- 실행 결과:
  - LLM 320회 호출, $19.07, 호출 오류 0
  - 컨테이너가 두 번 재시작됐다. 648턴 체크포인트부터 다시 돌렸다.

## 점수

| 그룹 | 평균 | 고정 대비 | 대화 없던 판 |
|---|---|---|---|
| 자유 `fw` | 60,095 | +6% | 68,071 (−5%) |
| 자유 `fr` | 57,768 | +2% | 76,208 (+6%) |
| 정책 고정 `st` | 56,708 | | 71,654 |
| v1 `cl` | 41,284 | −27% | 50,891 (−29%) |

- farm이 없으니 모두의 점수가 20% 안팎 낮다. 상대 순서는 비슷하다. 자유 16명의 평균(58,932)은 고정보다 4% 높다.
- 자리별로 보면 자유 플레이어가 고정을 이긴 자리는 8곳 중 5곳이다.
  - 많이 이긴 자리: miner2 +57%, turtle5 +41%, raider3 +31%
  - 진 자리: explorer7 −48%, hybrid8 −21%
- 1–3위는 st08, st07, cl07이다. 자유 플레이어의 최고는 4위 fr02였다.

## 대화

- 메시지는 89개였다. **전부 `all`(전체) 공지였고, 특정 플레이어에게 보낸 1:1 메시지는 0개였다.**
- 내용은 한 가지 틀을 반복했다. "먼저 공격하지 않고 경제·연구(후반에는 원정)에 집중한다. 공격받으면 방어하겠다. 서로 평화롭게 성장하자."
  - 0턴에는 16명 모두가 이 틀로 공지했다. 이후에는 갱신 한 번에 평균 2–4명이 같은 공지를 다시 올렸다.
  - 후반에 표현이 조금 세졌다. "공격받으면 강하게 방어하겠다"가 생겼고, 912턴에는 "방어하고 반격하겠다"(fw07)도 나왔다.
- 받은 메시지에 답하거나, 동맹·거래·위협을 제안한 메시지는 하나도 없었다. 공격한 상대를 이름으로 부른 메시지도 없었다.
  - 공격한 쪽은 전부 메시지를 읽지 못하는 규칙봇이었다.
  - 메시지를 읽는 자유 플레이어끼리는 협상할 거리 자체가 없었다(아래 공격 표).

## 공격 금지 선언 (`excluded_players`)

- 마지막 정책 기준으로 16명 중 8명이 목록을 썼다. 많게는 15명까지 적었다.
- 적힌 대상(전체 호출 누적, 선언한 쪽 → 대상 그룹):

  | 선언 | 자유 플레이어 | 고정봇 `st` |
  |---|---|---|
  | `fw` | 627 | 19 |
  | `fr` | 190 | 36 |

  거의 전부가 다른 자유 플레이어였다. 평화 공지를 보낸 상대를 금지 목록에 넣어 화답한 셈이다.
- 엔진이 목록을 강제하므로 약속을 깬 공격은 0번이다. 사실 자유 플레이어가 누군가를 공격한 일 자체가 없었다(아래).

## 누가 누구를 공격했나

| 공격 | 횟수 |
|---|---|
| 고정 → 자유 | 11 |
| v1 → 자유 | 10 |
| 고정 → v1·고정 | 12 |
| v1 → v1·고정 | 7 |
| **자유 → 누구든** | **0** |

- **자유 플레이어 16명은 960턴 동안 한 번도 공격하지 않았다.** farm이 있던 판에서는 farm을 1,151번 털었는데, farm이 없어지자 다른 플레이어를 노리지 않고 약탈을 아예 멈췄다.
- `priority_targets`에 다른 플레이어를 넣은 건 단 한 번이다. 912턴에 fr01이 "약한 st02의 큰 전리품 기회를 노린다"며 st02를 넣었다. 판이 끝나기 전에 공격은 나가지 않았다.
- 공격을 대신한 건 원정이었다. 원정 횟수는 fr 1,693, fw 1,637로 고정(1,057)과 v1(437)보다 많다. 원정에서 해적이나 외계인을 만나 잃은 자원은 fr 287만, fw 206만이다.
- 정찰선 손실도 작았다. fr 20만, fw 14만이다. 규칙봇은 그룹마다 260만 넘게 잃었다.

## 복수

- 자유 플레이어가 처음 공격당한 경우는 16번이다(공격자는 cl07, st03, st08 등).
- 그 뒤 반응:
  - 공격자를 우선 목표에 넣음: 0번
  - 공격자의 태양계를 피함: 0번
  - 되갚음: 0번
- 메시지로 공격자를 비난하거나 경고한 적도 없다. "공격받으면 방어하겠다"는 문장은 끝까지 일반론으로만 남았다.

## 해석

1. **대화를 줘도 외교는 생기지 않았다.** 16명이 같은 평화 공지를 반복했을 뿐, 상대를 골라 협상하거나 동맹을 맺지 않았다. 같은 모델, 같은 프롬프트라 생각도 같고, 서로에게 할 말이 없다.
2. **farm을 없애도 전쟁은 생기지 않았다.** LLM은 다른 플레이어를 약탈하는 대신 원정과 경제로 옮겨 갔다. "먼저 공격하지 않는다"가 지난판에는 목표 문장으로만 있었는데, 이번에는 행동으로도 지켜졌다(공격 0).
3. **평화주의가 손해는 아니었다.** 자유 그룹은 공격 없이도 고정 정책보다 4% 높았다. 고정 raider 자리(raider3·4)의 점수가 낮은 걸 보면, 이 세계에서는 플레이어 약탈의 수익이 적다.
4. 공격은 전부 규칙봇이 했다. 규칙봇은 메시지를 읽지 못하므로, 대화나 공격 금지 선언이 이들을 막을 수 없다. 외교가 의미를 가지려면 공격하는 쪽도 메시지를 읽어야 한다.

## 대화만 넣은 판 (freeworld_chat_farm)

대화의 효과만 따로 보려고, 대화 없던 자유 세계 판(`freeworld`)과 같은 설정(seed 7, farm 8개)에 대화 기능만 더해 한 판 더 돌렸다.

- 설정 파일: `sim/configs/freeworld_chat_farm.json`
- LLM 320회 호출, $19.77, 호출 오류 0
- 컨테이너가 한 번 재시작됐다. 648턴 체크포인트부터 다시 돌렸다.

### 점수

| 그룹 | 대화 없음 (`freeworld`) | 대화 있음 (`freeworld_chat_farm`) |
|---|---|---|
| 자유 `fr` | 76,208 | 71,757 |
| 자유 `fw` | 68,071 | 59,862 |
| 정책 고정 `st` | 71,654 | 65,523 |
| v1 `cl` | 50,891 | 48,927 |
| 자유 16명 평균, 고정 대비 | +0.7% | +0.4% |
| 자유가 이긴 자리 | 5/8 | 5/8 |

- 모든 그룹의 점수가 함께 낮아졌다. 고정 대비 차이는 거의 같다. 같은 seed라도 LLM 응답이 매번 달라서 판마다 흔들리므로, 점수 차이는 대화 효과라고 보기 어렵다.
- 1위는 자유 플레이어 fr06(92,070)이었다.

### 대화

- 메시지 70개 중 67개가 `all` 공지였다. 내용은 farm이 없던 판과 같은 틀에 "비활성 farm만 노리겠다"는 말이 붙었다. 후반에는 "**활성 플레이어는** 먼저 공격하지 않는다"로 굳었다.
- 1:1 메시지는 3개뿐이다. 288턴에 fr03, fr04, fw01이 fr01의 평화 공지에 답했다. "평화 제안 감사합니다. 저도 먼저 공격하지 않고 farm 행성만 노리겠습니다." 이번 시리즈를 통틀어 유일한 '대답'이다.
- 협상, 동맹, 위협, 비난은 이번에도 없었다. 16명이 같은 farm 8개를 나눠 터는 상황이었지만, farm을 나누자는 제안도 나오지 않았다.

### 공격

| 공격 | 대화 없음 | 대화 있음 |
|---|---|---|
| 자유 → farm | 1,151 | 1,140 |
| 자유 → 다른 플레이어 | 11 | **1** |
| 규칙봇 → farm | 372 | 480 |
| 규칙봇 → 자유 | 26 | 36 |
| 규칙봇끼리 | 11 | 15 |

- **자유 플레이어가 다른 플레이어를 공격한 횟수가 11번에서 1번으로 줄었다.** 서로를 `excluded_players`에 넣었기 때문이다(누적 607회, 전부 다른 자유 플레이어). 대화가 없던 판에서는 목표 문장이 "먼저 공격하지 않는다"인데도 엔진이 근처 플레이어를 털었다. 이번에는 선언이 엔진에 걸려서 실제로 지켜졌다.
- 남은 1번은 fw08 → fr08이다. fw08은 "먼저 공격하지 않겠다"고 공지했지만, fr08을 금지 목록에 넣지 않았다. 그래서 엔진이 약탈 기준을 넘는 fr08을 털었다. 말과 행동의 틈이 한 번 남은 셈이다.
- 그만큼 규칙봇이 farm과 자유 플레이어를 조금 더 털었다(372 → 480, 26 → 36).
- 공격당한 뒤의 반응(우선 목표, 회피, 되갚기)은 25번 중 0번이다. 대화 없던 판(23번 중 0번)과 같다.

### 세 판을 함께 보면

1. **대화 기능은 '말'만 바꿨다.** 16명이 같은 평화 공지를 반복했고, 상대를 골라 협상하지 않았다. 같은 모델, 같은 프롬프트라 서로에게 할 말이 없다.
2. **행동을 바꾼 건 엔진에 걸리는 선언(`excluded_players`)이다.** 자유 플레이어끼리의 공격이 사라졌다(11 → 1, farm이 없을 때 0).
3. **복수는 세 판 모두 0이다.** 공격 기록과 메시지를 다 줘도 LLM은 공격자를 노리지 않았다. 공격자는 메시지를 못 읽는 규칙봇이었다.
4. **점수는 세 판 모두 고정 정책과 비슷하다**(+0.4% ~ +4%). 평화주의가 손해는 아니었다.
