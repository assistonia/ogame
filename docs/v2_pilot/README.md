## 고친 버그(1~3차 파일럿 폐기 사유)

1. `users.planet_current`가 비어 봇이 DB에서 자원 상태를 못 읽음 → 창고·에너지 규칙이 꺼진 채 전원 자원 상한에 막힘.
2. farm을 마지막에 시드해 은하 끝에 몰림 → 레이더 탐색 범위(±2 태양계) 밖.
3. 정찰 보고서 나이를 DB `NOW()`(실제 시각)로 계산 → 가상 시계와 어긋나 모든 보고서가 "오래됨" → 공격 불가.
