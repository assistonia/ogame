## 두 판을 합친 결론

| | main1 (seed 1, 16턴) | main2 (seed 2, 32턴) |
|---|---|---|
| LLM vs 고정 | -13% (2/8) | +1% (4/8) |
| LLM 잠금 vs 고정 | — | -12% (2/8) |
| v1 vs 고정 | -29% | -24% |

1. **LLM 정책 조정은 고정 정책을 이기지 못한다.** 두 판 합쳐 16자리 중 6승, 평균 약 -6%. 판마다 결과가 크게 달라서(-13% → +1%) "확실히 더 나쁘다"고도 할 수 없다.
2. **판 안의 잡음이 크다.** 같은 고정 정책·같은 성향인데 st03 65k vs st04 41k(±25%). 자리별 ±30% 이내 차이는 대부분 잡음으로 봐야 한다.
3. **유일하게 일관된 패턴은 miner 자리.** 두 판, 두 LLM 그룹 모두 6/6 자리에서 고정보다 낮았다(-16% ~ -40%). LLM miner는 동시 미션을 1~2개로 묶고 약탈을 거의 안 했다(ll01·ll02 공격 0). 고정 miner는 엔진 기본값으로 약탈(16·28회)과 원정을 같이 했다.
4. **잠금은 도움이 안 됐다.** 성향·방어 비율을 막아도 -12%. main1에서 의심했던 방어 과투자가 주원인은 아니다. 남은 후보는 함선·미션 설정(aggression, ship_strategy)과 건설·연구 우선순위.
5. **LLM 비잠금 그룹은 두 판 모두 약탈이 가장 적고 가장 많이 털렸다** (main1 142회/32회, main2 78회/26회). 레이더를 hybrid로 바꾸는 경향도 두 판 모두 나타났다.
6. **v2 정책 엔진은 v1 규칙봇보다 두 판 모두 24~29% 높다.** LLM 여부와 상관없는 가장 확실한 차이.
