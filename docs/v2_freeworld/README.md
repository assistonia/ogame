# v2 자유 세계 실험 (freeworld)

LLM 플레이어에게 역할을 정해 주지 않으면 어떤 세계가 되는지 보려고 돌린 실험이다.

## 설정

- 설정 파일: `sim/configs/freeworld.json` (seed 7, 960턴 = 게임 시간 10일)
- 플레이어 구성:
  - 자유 LLM 16명 (`fr01–08`, `fw01–08`)
  - v1 규칙봇 8명 (`cl`)
  - 정책 고정봇 8명 (`st`)
  - 비활성 farm 8개
- 자유 LLM 플레이어에게 주어진 것:
  - 정해진 목표나 역할이 없다. 처음에는 모두 hybrid로 시작한다.
  - 48턴(게임 시간 12시간)마다 스스로 할 일을 정한다.
    - `goal`: 지금 무엇을 노리는지 자유롭게 적는 글
    - `priority_targets`: 먼저 노릴 좌표
    - `excluded_systems`: 건드리지 않을 태양계
    - 그 밖의 정책 항목 전부
  - 판단 재료로 전체 세계 정보를 받는다.
    - 모든 플레이어의 행성, 점수, 군사력, 비활성 여부
    - 플레이어끼리 누가 누구를 몇 번 공격했는지 (전체 누적, 최근 12시간)
  - 플레이어끼리 대화하는 기능은 없다.
- 실행 결과:
  - LLM 336회 호출, $19.78, 호출 오류 0
  - 컨테이너가 한 번 재시작됐다(925턴). 912턴 체크포인트에서 이어서 돌렸다.
- 분석: `python3 -m sim.analyze_freeworld runs/freeworld`

## 점수

| 그룹 | 평균 | 비고 |
|---|---|---|
| 자유 `fr` | **76,208** | 고정 대비 +6% |
| 정책 고정 `st` | 71,654 | |
| 자유 `fw` | 68,071 | 고정 대비 −5% |
| v1 `cl` | 50,891 | 고정 대비 −29% |

- 자유 16명을 합친 평균은 72,140이다. 고정 정책(71,654)과 사실상 같다.
- 순위:
  - 1위 st08 (hybrid), 2위 fr08, 3위 st07 (explorer)
  - 상위 10명 중 6명이 자유 플레이어다.
  - 자유 플레이어는 모두 32명 중 2–24위 안에 들었다. 하위 8자리(25–32위)는 v1 규칙봇과 고정 turtle·miner 차지다.
- 자유 플레이어 16명 사이의 편차(5.5만–9.5만)는 고정 그룹(4.5만–9.7만)보다 작았다. 고정 그룹의 turtle과 miner처럼 크게 뒤처지는 자리가 없었다.
- 주의: 시드 실험의 LLM 그룹(`ll`)과는 바로 비교할 수 없다. `ll`은 자리마다 성향이 정해진 채 시작했고, 이번 판은 seed와 그룹 구성도 다르다.

## 무엇을 목표로 삼았나

**모두가 "경제를 키우고 비활성 farm을 턴다"로 시작했다.** 16명의 0턴 목표가 거의 같았다. 이후 목표가 바뀐 흐름은 다음과 같다.

| 시기 | 주된 목표 |
|---|---|
| 0–240턴 | 약탈 준비. 정찰기 7기가 갖춰져야 약탈을 시작하는 엔진 규칙에 막혀, 크리스탈 광산과 정찰기 확보에 매달렸다. "정찰기 대기를 멈추고 지금 있는 함대로 시작한다"처럼 규칙을 우회하는 방법을 찾는 봇도 있었다. |
| 240–480턴 | 화물 용량. "약탈 가능량 22만에 비해 화물칸이 7.5만이다"처럼 숫자를 근거로 대형 화물선을 늘렸다. |
| 480–720턴 | 저장고 포화와 에너지 부족 해결. 남는 금속은 방어나 함선으로 돌렸다. |
| 720–960턴 | 점수 굳히기. 전함, 순양함, 방어 시설, 원정에 투자했다. fr08은 "농장 약탈은 전리품이 거의 0이라 중단"하고 원정으로 돌아섰고, 마지막에는 "1위 점수를 유지한다"를 목표로 적었다. |

- 봇마다 목표 문장을 17–20번 바꿨다. 그래도 큰 방향(경제 → 약탈 → 점수)은 16명이 거의 같았다.
- 전쟁광, 동맹 같은 뚜렷한 정체성은 나오지 않았다.

**아무도 시키지 않은 "먼저 공격하지 않는다"는 규범이 생겼다.**

- 0턴부터 이렇게 쓴 봇이 있었다(fr05, fw01, fw03, fw05, fw07).
- 마지막 목표에 이 문장이 남은 봇은 `fw`에서 8명 중 6명, `fr`에서 8명 중 1명이었다.
  - 표현은 이런 식이었다. "활성 플레이어는 먼저 공격하지 않는다", "먼저 시비를 걸지 않는다", "이웃은 건드리지 않는다".
- 같은 모델, 같은 프롬프트인데 그룹마다 비율이 갈렸다. 그룹을 나눈 건 이름뿐이라 순전히 우연일 가능성이 크다.
- 그래도 결과는 갈렸다. `fw`는 공격을 26번 받았고 점수는 −5%였다. `fr`은 6번 받았고 +6%였다.

## 누가 누구를 노렸나

- 자유 플레이어가 고른 `priority_targets` 1,938개는 **전부 비활성 farm 좌표**였다.
- `excluded_systems`(피할 태양계)를 쓴 봇은 하나도 없었다.

공격 횟수 (공격한 쪽 → 공격받은 쪽):

| 공격 | 횟수 |
|---|---|
| 자유 → farm | 1,151 (fr 591, fw 560) |
| v1·고정 → farm | 372 |
| 고정 → 자유 | 17 |
| v1 → 자유 | 9 |
| 자유 → 자유 | 6 |
| 자유 → v1·고정 | 5 |
| 규칙봇끼리 | 11 |

- **자유 플레이어는 farm을 규칙봇보다 약 3배 자주 털었다.** 다만 1회 평균 약탈량은 fr 7.9k, fw 5.4k로, v1(33.8k)과 고정(15.0k)보다 훨씬 적었다. 16명이 같은 farm 8개를 동시에 노렸기 때문에 farm이 늘 거의 비어 있었다.
- 자유 플레이어가 다른 플레이어를 공격한 11번은 LLM이 지목한 것이 아니다. 엔진이 근처 행성을 정찰한 뒤 약탈 기준을 넘는 목표를 공격한 것이다. 예를 들어 fr05는 "먼저 시비를 걸지 않는다"고 쓰고도 cl08을 세 번 공격했다. 목표 문장과 엔진의 실제 행동이 따로 노는 경우다.
- 정찰선 손실이 아주 적었다: fr 45만, fw 14만. 고정은 223만, v1은 142만이었다.

## 복수·회피·휴전

- 자유 플레이어가 처음 공격당한 경우는 23번이다. 그 뒤 반응은 다음과 같다.
  - 공격자를 우선 목표에 넣음: 0번
  - 공격자의 태양계를 피함: 0번
  - 같은 상대에게 되갚음: 0번
- 공격당한 직후 남긴 메모도 전부 경제 이야기였다(저장고, 에너지, 크리스탈 부족 등).
- 공격 기록은 세계 정보로 받았지만, 결정에 반영된 흔적은 없다.
- "보복하지 않음"과 "먼저 공격하지 않음"이 함께 나타났으니, 일종의 일방적 평화주의라고 볼 수 있다. 상대와 약속하는 휴전은 대화 기능이 없어서 생길 수 없다.

## 해석

1. LLM은 역할이 없으면 가장 안전하고 확실한 수익원(비활성 계정)으로 몰린다. 다른 플레이어와의 전쟁은 위험하다고 보고 피한다.
2. 그 결과 farm의 자원이 바닥났다. 그래서 후반에는 원정과 함대로 점수를 쌓는 쪽으로 옮겨 갔다. 세계 전체로 보면 자원 고갈에 대한 적응이다.
3. 정해진 역할 없이 시작한 자유 플레이어는 평균적으로 고정 정책과 비슷했다. 다만 크게 뒤처지는 자리가 없었다. 시드 실험에서 LLM이 졌던 원인이 자리에 묶인 성향(특히 miner) 때문이었다는 해석과 맞는다. 단, 한 판뿐인 결과다.
4. LLM이 쓴 목표 문장과 엔진이 실제로 하는 행동 사이에 틈이 있다. "먼저 공격하지 않는다"를 지키게 하려면, 활성 플레이어를 정찰·공격 대상에서 빼는 정책 항목이 필요하다.
